# 뉴니버스 설정 v1 (시험판) 설치 방법
안내 페이지: https://guy06891577-svg.github.io/newniverse-sand/apk/settings.html
내려받기: https://guy06891577-svg.github.io/newniverse-sand/apk/newniverse-settings-v1-test.apk
패키지 kr.newniverse.settings · 버전 1-test (versionCode 1) · 런처·전화·문자·계산기와 같은 뉴니버스 릴리스 서명

1. 이 폰의 크롬에서 위 내려받기 → 내 파일 › 다운로드 › newniverse-settings-v1-test.apk → (출처 허용) → 설치.
2. 앱 목록에서 '뉴니버스 설정'을 여세요.

권한: WRITE_SETTINGS(밝기·자동 회전, 처음 한 번 허용 안내 창), ACCESS_NOTIFICATION_POLICY(무음, 방해 금지 접근 허용), ACCESS_WIFI_STATE(Wi-Fi 켜짐 표시). 인터넷 권한 없음.
바로 바뀜: 소리/진동, 손전등, (허용 후) 밝기·자동 밝기·자동 회전·무음. 안드로이드 창/설정 화면으로 이동: Wi-Fi, 모바일 데이터, NFC, 블루투스, 비행기 모드, 위치, 핫스팟, 방해 금지.
빌드: ./build.sh (aapt2 · javac 17 · d8 · zipalign · apksigner, android-34, minSdk 26). 서명 키와 비밀번호는 저장소에 없음.
검사: /workspace/nvtmp/capset1.py (정적 검사 + 360x640·412x915 레이아웃/동작/브리지 없음·오류 모드), 캡처 /workspace/nvtmp/settings1/
