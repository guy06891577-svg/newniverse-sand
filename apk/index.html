v46 새로워진 점 · 훨씬 고운 모래 · 홈은 검색창만 · 진짜 버전 표시

  • 모래알이 훨씬 고와졌어요: 알갱이가 더 작아지고, 날아다니는 동안 번져 보이던 부분을 줄여서 고운 모래가루처럼 보여요. 설정 › 홈 화면 › 모래 전환 › 모래알 크기가 0.5까지 내려가요(기본 0.75). 폰이 버거워하면 알아서 알갱이 수를 줄여서 끊기지 않게 맞춰요.
  • 홈에는 검색창만 보여요. 버스·길찾기·전화 칩과 「모든 앱」 칩을 없앴어요. 화면을 위로 밀면 나오는 최근 앱 화면에 「모든 앱」 단추가 있어요.
  • 「유니 설정」이라는 별명을 없앴어요. 「뉴니버스 설정」이라고 해 주세요.
  • 설정 › 폰 정보가 폰에 실제로 깔린 버전을 보여 줘요(런처와 깔려 있는 문자·전화·설정·계산기 앱).

v45 새로워진 점 · 앱 길게 누르기 · 모든 앱 · 설정 · 문자 카드 켜기

  • 앱을 길게 누르면 앱 서랍·검색 결과·최근에 쓴 앱(별)·최근 앱 화면 어디서든 앱 정보 · 삭제 메뉴가 떠요. 기본(시스템) 앱은 삭제가 안 보여요.
  • 모든 앱: 최근 앱 화면의 「모든 앱」 단추로 전체 앱 목록을 바로 열어요. 「앱」이라고 쳐도 돼요.
  • 「설정」은 안드로이드 설정을, 「뉴니버스 설정」은 뉴니버스 설정 앱을 열어요.
  • 문자 속 할 일 카드: 뉴니버스 문자가 깔려 있고 기본 문자 앱이면, 켜기 카드가 홈에 한 번 저절로 떠요. 연결이 막히면 이유를 카드로 알려 드려요. 약속 카드는 14일 안 것을 가까운 순으로(최대 2장) 보여요.

v44 새로워진 점 · 말하기·글씨로 전원 창 (시험)

  • 같은 입력칸에 「다시 시작」「재시작」「종료」「전원 꺼」「전원 메뉴」라고 말하거나 쓰면, 안드로이드의 전원 창만 열어 드려요. 끄거나 다시 시작하는 단추는 직접 눌러 주세요. 뉴니버스가 전원을 끄거나 다시 시작하지는 않아요.
  • 설정 › 홈 위쪽 「말하기·글씨로 전원 창 열기」 스위치로 켜요. 기본은 꺼져 있어요. 처음 한 번, 왜 접근성이 필요한지 쉬운 말로 안내한 뒤 뉴니버스 전원 창 접근성 설정으로 데려가요. 접근성이 꺼져 있으면 안내 카드와 설정 단추만 보여 줘요.
  • 이 접근성 서비스는 전원 창을 띄우는 동작만 해요. 화면의 글자·비밀번호·입력 내용은 읽거나 저장하거나 보내지 않아요.
  • 「앱 종료」「음악 종료」「통화 종료」처럼 다른 대상을 끝내는 말은 전원 창을 열지 않아요.
  • 이 기능은 시험판이에요. Play 스토어에 올리려면 접근성 선언서를 내거나, 이 서비스를 뺀 판(./build.sh basic play · ./build.sh plus play)을 써야 해요.

v43 새로워진 점 · 문자 속 할 일 카드 · 살아 있는 우주

  • 문자 속 할 일 카드(처음 켤 때 한 번 설명): 택배(회사·운송장·도착/배송 완료) · 병원 예약(병원 이름·날짜·시간) · 카드 결제(카드사·금액·가게) · 인증번호(복사 단추, 3분 뒤 저절로 사라짐)를 우주에 유리 카드로 보여 줘요. 빈 우주 원칙대로 저절로 뜨는 건 최대 2장(방금 온 인증번호·오늘/내일 택배·예약)이고 모래처럼 흩어지며 사라져요. 나머지는 물어보면 나와요.
  • 같은 입력칸에 「택배 언제 와」「병원 예약 언제야」「준혁이 병원 언제지?」「오늘 카드 얼마 썼어」「인증번호」라고 말하거나 쓰면 카드가 뜨고 한국어로 읽어 줘요(무음·진동·방해 금지면 읽지 않고 안내만). 앱 이름·설정·날씨·검색은 가로채지 않아요.
  • 문자 권한은 런처가 받지 않아요. Google Play 정책상 문자 권한은 기본 문자 앱만 쓸 수 있어서, 뉴니버스 문자 v8(같은 서명, 기본 문자 앱)가 택배·예약·카드·인증 문자만 골라 서명 수준 권한이 걸린 통로로 런처에 넘겨 줘요. 뉴니버스 문자가 없거나 기본 문자 앱이 아니면 짧은 안내 카드(문자 앱 열기)만 보여 주고 기능은 꺼져 있어요. 인터넷은 쓰지 않고 문자를 저장하지 않아요.
  • 예약 카드의 「달력에 추가」 단추 → 뉴니버스 문자가 ‘뉴니버스’ 전용 달력에 넣어요(자세한 건 뉴니버스 문자 설치 페이지). 설정 › 홈 위쪽 「문자 속 할 일 카드」 스위치로 켜고 꺼요.
  • 살아 있는 우주: 별 몇 개가 천천히 반짝이고 배경이 아주 느리게 흘러요(하늘색·보라). 화면이 꺼지거나 숨으면 멈추고, 절전·가벼운 모드·‘애니메이션 끔’·‘동작 줄이기’에서도 움직이지 않아요. 배터리를 거의 쓰지 않는 CSS 애니메이션이에요.
  • 이 버전과 같이 뉴니버스 문자 v8를 설치하고 기본 문자 앱으로 지정해야 카드가 나와요.

v42 새로워진 점 · 날씨 읽어 주기 · 웹 검색

  • 같은 입력칸에 「날씨」「오늘 날씨」「날씨 어때」「밖에 추워?」「비 와?」「우산 필요해?」라고 말하거나 쓰면, 유리 카드에 오늘 날씨(하늘 상태·지금 기온·최고·최저·습도·바람 방향과 세기)가 나와요. 위치를 못 읽으면 안동 날씨를 보여 줘요.
  • 카드를 보여 주며 한국어로 읽어 줘요. 예: 「지금 안동은 맑고 기온 5도, 습도 40퍼센트, 북서풍 초속 3미터예요.」 무음·진동이거나 방해 금지가 켜져 있으면 읽지 않고 카드만 보여 주고, 작은 선 아이콘으로 알려 줘요. 스피커 단추를 누르면 다시 듣거나 멈출 수 있어요.
  • 날씨는 기상청 초단기실황(뉴니버스 중계 서버)을 쓰고, 최고·최저처럼 없는 값은 무료 Open-Meteo로 보완해요. 받아 온 시각을 카드에 적고, 인터넷이 안 되면 마지막 값을 보여 줘요.
  • 「라면 검색해줘」「라면 찾아줘」「구글에서 라면」처럼 말하면 기본 브라우저가 열려요. 기본은 네이버, 「구글」이라고 하면 구글이에요. 앱이나 설정·날씨로 안 알아들은 말은 「네이버에서 “…” 검색」 한 줄을 보여 주고, 누르기 전에는 검색하지 않아요. 「카카오뱅크」만 말하면 은행 앱이 나와요.

v41 새로워진 점 · 말이나 글씨로 폰 설정 바꾸기

  • 앱 없는 홈의 같은 입력칸(말하기·두 번 톡톡 포함)에 「밝기 올려줘」「화면 좀 밝게」「어둡게」「무음」「진동」「손전등 켜줘」「볼륨 키워」처럼 말하거나 쓰면 바로 바꿔요. 바꾼 뒤에는 작은 유리 카드가 결과(예: 밝기 70%)를 보여 주고, 밝기·볼륨은 슬라이더, 나머지는 되돌리기 단추가 있어요. 잠시 뒤 모래처럼 흩어지며 우주로 돌아가요.
  • 바로 바뀌는 것: 밝기(올려/내려/최대/최소/70%)·자동 밝기·자동 회전(‘시스템 설정 변경’ 허용 필요), 무음·방해 금지(‘방해 금지 접근’ 허용 필요), 진동·소리 모드·손전등·미디어 볼륨(허용 필요 없음).
  • 시스템 창을 열어 주는 것(안드로이드가 앱의 직접 켜고 끄기를 막아 놨어요): 와이파이·모바일 데이터·NFC·비행기 모드는 설정 창, 블루투스·위치·핫스팟은 해당 설정 화면.
  • 허용이 필요할 때는 처음 한 번만 쉬운 말로 설명한 뒤 허용 화면으로 데려가고, 돌아오면 하려던 일을 이어서 해요. 허용은 그 기능을 처음 쓸 때만 물어봐요.
  • 「밝기」「소리」처럼 뜻이 여러 개면 자동으로 하지 않고 선택 칸을 보여 줘요. 밤에는 입력칸 아래 희미한 제안어에 무음·밝기가 떠요.

v40 새로워진 점 · 두 번 톡톡으로 말하기 · 영어 앱 이름 · 잠금화면

  • 앱 없는 홈(우주)에서 빈 곳을 톡톡 두 번 누르면, 마이크 단추와 같이 폰의 음성 인식 화면이 열려요. 말할 때 작은 물결·입력칸 빛이 살짝 보여요. 마이크 단추는 그대로 있습니다.
  • 예전 아이콘 홈에서는 두 번 톡톡이 예전처럼 화면 끄기(기본판은 어둡게)예요.
  • 영어 이름 앱도 한국 발음·초성으로 찾아요. 예: 그록봇·ㄱㄹㅂ → Grok Bot, 유튜브·ㅇㅌㅂ → YouTube, 인스타·ㅇㅅㅌ → Instagram. 조금 다르게 알아들어도 가까운 앱을 고릅니다.
  • 잠금화면에는 검색창과 전화/문자/계산 낱말이 없어요. 시계·알림·「위로 쓸어 올려 잠금 해제」·모서리의 전화·카메라만 보여요. 단추와 안내가 겹치지 않게 자리를 바꿨어요.
  • 잠금화면 알림은 실제 알림만 보여요(알림 접근을 켠 경우). 예전처럼 「엄마」「서울 날씨」 같은 예시 내용은 넣지 않아요. 날씨는 실제 위치(못 읽으면 안동)의 기상청 값만 보여요.

v39 새로워진 점 · 말로 찾기 · 모래 효과

  • 🎤 마이크 단추를 누르면 이제 폰의 음성 인식 화면이 열려요. 「무엇을 하실 건가요?」라고 적힌 화면에서 말한 뒤 끝나면, 뉴니버스가 그 말로 앱을 찾아요. 삼성·구글이 쓰던 그 화면이라 알아듣기가 더 정확해요.
  • 말은 여러 후보를 받아서 그중 가장 맞는 뜻을 고르고, 들린 글자는 아래 입력칸에 보여 드려요. 「입금해야겠다」「사진 찍어볼까」「돈 보내줘」「카톡 열어줘」처럼 조금 길게 말해도 돼요.
  • 앱 칸이 나타나고 사라질 때, 앱을 열 때는 예전처럼 모래가 모이고 흩어지는 효과를 씁니다.
  • 마이크 단추는 그대로 둡니다. (화면이 꺼진 뒤 두 번 톡톡으로 바로 듣기은 나중에 잠금화면 작업이 필요해요. 지금은 두 번 톡톡이 화면을 끄는 동작 그대로입니다.)

v38 새로워진 점 · 앱 없는 홈

  • 홈을 열면 아이콘·독 대신 우주 그림과 아래쪽 「무엇을 하실 건가요?」 칸만 보여요. 아래에는 안드로이드 이동 막대만 있어요.
  • 칸에 앱 이름·초성·하고 싶은 일을 치면 치는 동안 바로 앱이 떠요. 예: 입금·송금·은행 → 은행 앱들이 반듯하게 한 줄로, 사진 → 카메라, 계산 → 뉴니버스 계산기, 설정 → 뉴니버스 설정, 전화·문자 → 뉴니버스 전화·문자, 버스 → 버스 도착 카드. 엔터를 누르면 첫 번째 앱이 열려요.
  • 🎤 마이크 단추를 누르면 말로도 돼요(한국어). 처음 한 번 마이크 허락을 물어요. 단추를 누른 동안에만 듣고, 녹음은 남기지 않아요. 폰에 한국어 음성 인식이 없으면 안내만 나오고 글자로 쓰면 돼요.
  • 칸 아래 희미한 제안 낱말 2~3개(시간에 따라 바뀜), 아침(6시~9시 반)에는 버스 카드가 위쪽에 떠올라요.
  • 화면을 위로 밀면 최근에 쓴 앱이 별자리처럼 떠요. 「모든 앱」을 누르면 예전 앱 목록. 아래로 밀면 빠른 설정, 빈 곳 길게 누르면 메뉴, 두 번 톡톡은 그대로예요.
  • 예전 아이콘 홈(독·위젯·여러 쪽)이 좋으면: 빈 곳 길게 누르기 › 예전 홈으로, 또는 홈 화면 설정 › 앱 없는 홈 (우주) 끄기. 언제든 다시 켤 수 있어요.

v37 새로워진 점 · 독 문자 · 독 5칸

  • 뉴니버스 문자를 깐 폰은 독의 문자(메시지)를 누르면 뉴니버스 문자가 열려요. 기본 문자 앱으로 정했는지와 상관없어요. 전화가 뉴니버스 전화를 여는 것과 같은 방식이에요.
  • v36b를 쓰던 폰도 덮어 깔면 독의 삼성 메시지 칸이 한 번만 뉴니버스 문자로 바뀌어요. 독에서 직접 뺀 아이콘(예: 인터넷)은 다시 넣지 않아요. 뉴니버스 문자를 지우면 원래 문자 앱으로 돌아가요.
  • 검색에서 연락처의 ‘문자’를 눌러도 뉴니버스 문자가 열려요.
  • 독에 앱을 5개까지 둘 수 있어요. 홈 화면 아이콘을 길게 누른 채 독의 빈 곳으로 끌어다 놓으면 들어가요. 5개가 차면 더 들어가지 않고 ‘독이 꽉 찼어요’가 떠요. 처음 독은 그대로 전화·메시지·인터넷 3개예요.

v36 새로워진 점 · 버스 방면 · 깜빡임 없앰

  • 버스 카드에 어느 방면으로 가는지가 나와요. 예: 510 4분 · 교보생명 방면. 안동시 버스정보시스템이 알려주는 그 차의 종점이에요. 펼치면 노선마다 방면이 함께 보여요.
  • 순환 노선(출발·종점이 같은 노선)이나 방향 정보를 주지 않는 지역(국토교통부 TAGO로 받는 안동 밖 지역)은 방면을 비워 둬요. 짐작해서 쓰지 않아요.
  • 홈에서 앱을 지울 때 아래 버스 카드가 사라졌다 다시 나타나던 것을 고쳤어요. 길게 누르기 메뉴·삭제 확인 창이 떠도 카드가 그대로 있고, 지운 앱 자리만 정리돼요. 앱 설치·폴더 만들기·화면 넘기기에서도 버스 카드와 위젯이 다시 만들어지지 않아요.
  • 처음 켤 때 나오는 ‘옆으로 밀어 다음 화면’ 안내가 마지막 줄 앱 이름과 겹치면, 그 자리 대신 한 번만 알림 문구로 보여줘요.

v35 새로워진 점 · 독 정리

  • 아래 독에서 연락처(주소록)를 뺐어요. 주소록은 이제 뉴니버스 전화 앱 안의 탭이에요. 독은 전화 · 메시지 · 인터넷 3개가 같은 간격으로 놓여요(궤도·모래언덕·보자기 모양에서도 3개).
  • v34b를 쓰던 폰도 덮어 깔면 독에서 연락처가 한 번만 빠져요. 연락처 앱은 지워지지 않고 위로 밀어 여는 전체 앱에 그대로 있어요. 다시 독에 두고 싶으면 아이콘을 길게 눌러 독에 추가하면 그대로 남아요.
  • 뉴니버스 전화를 깐 폰에서 독의 전화가 껐다 켠 뒤 원래 전화 앱으로 돌아갈 수 있던 저장 문제를 고쳤어요.

v34 새로워진 점 · 날씨·미세먼지 바로 보기 · 버스 카드 고침

  • 위치를 이미 허락한 폰(버스 알림을 켠 폰)은 깔자마자 홈 시계에 미세먼지·초미세먼지가 저절로 떠요. (v33에서는 설정에서 직접 켜야 해서 안 보였어요.) 끄고 싶으면 ⚙ 설정 › 위치 › 홈 시계에 날씨·미세먼지.
  • 날씨: 시계 아래 줄에 기온과 하늘 상태(예: 9° 구름많음)가 배터리 앞에 나와요. 정보 출처: 기상청. 공공데이터포털 기상청 단기예보 사용 신청이 끝나면 앱을 다시 깔지 않아도 보여요(그 전에는 미세먼지만).
  • 시계의 날씨나 미세먼지를 누르면 습도·㎍/㎥ 숫자·측정소가 나와요.
  • 버스 카드(홈 하단 고정): 이제 닫기 단추가 없어요. 누르면 펼치고, 다시 누르면 접혀요. 예전처럼 ‘닫았어요’에 멈추지 않아요.
  • ‘가까운 정류장이 없어요’ 카드를 누르면 설정으로 가지 않고 바로 다시 찾아요.
  • 다른 홈 스타일(궤도 등)의 떠 있는 카드는 닫기를 두 번 눌러야 닫혀요(실수 방지).
  • 위치가 꺼져 있거나 허락이 없으면 시계 오른쪽 아래와 버스 카드에 원인(예: ‘폰 위치(GPS) 꺼짐’)이 떠요. 누르면 설정으로 가요.
  • 폰 정보 화면에 모델이 ‘뉴니버스 런처 앱 0.34b’로 나오고(예전 ‘시제품 (웹)’ 문구는 잘못 붙어 있던 것), 위치 허락 · 중계 서버 연결 · 버스 · 날씨 상태가 한눈에 보여요. 기본 홈 앱이 아니어도 버스와 날씨·미세먼지는 똑같이 돼요.
  • 새 권한 없음.

v33 새로워진 점 · 미세먼지 · 뉴니버스 전화

  • 홈 시계에 미세먼지: ⚙ 설정 › 위치 › 홈 시계에 미세먼지를 켜면 큰 시계 오른쪽에 미세먼지·초미세먼지가 좋음 · 보통 · 나쁨 · 매우나쁨으로 떠요. 누르면 숫자(㎍/㎥)와 측정소가 나와요. 정보 출처: 에어코리아(한국환경공단).
  • 지금은 공공데이터포털 에어코리아 사용 신청이 끝나야 값이 나와요. 신청 전에는 설정에 ‘준비 중’으로 보이고 시계 옆은 비어 있어요. 신청이 끝나면 앱을 다시 깔 필요 없이 바로 보여요.
  • 위치는 켤 때만 물어보고(버스 알림과 같은 권한), 뉴니버스 화면이 보일 때 30분에 한 번만 약 1km 단위로 읽어요.
  • 독의 전화 아이콘: 뉴니버스 전화가 깔려 있으면 그 앱이 열려요. 뉴니버스 전화를 지우면 원래 전화 앱으로 저절로 돌아가요. 연락처 검색의 ‘전화’도 뉴니버스 전화 키패드로 열려요.
  • 새 권한 없음.

v32 새로워진 점 · 버스 카드 고정

  • 버스 알림을 켜 두면 카드가 홈 화면 맨 아래, 독 바로 위에 붙어 있어요. 모든 홈 화면에서 같은 자리이고, 화면을 넘길 때도 모래처럼 흩어지지 않아요.
  • ⚙ 설정 › 위치 › 버스 카드 위치에서 하단(기본) / 상단(맨 위)을 고를 수 있어요. 하단은 누르면 위로, 상단은 아래로 펼쳐져요.
  • 아이콘 이름을 가리지 않게 아이콘 줄 간격을 그만큼 줄여요(아이콘 수와 배치는 그대로). 버스 알림을 끄면 원래 간격으로 돌아가요.
  • 근처에 정류장이 없을 땐 같은 자리에 ‘가까운 정류장이 없어요’가 작게 떠 있어요(누르면 위치 설정).

v31 새로워진 점 · 안동 버스 도착 시간

  • 안동도 이제 몇 분 뒤, 몇 정류장 전인지 나와요. 안동시가 공개한 안동시 버스정보시스템 정보를 뉴니버스 중계 서버가 받아 전해 줘요 (안동시 BIS 누리집의 ‘약 N분후 도착’과 같은 값). 그 서버가 안 되면 예전처럼 노선만 보여요.
  • 자주 타는 버스 알림도 안동에서 돼요 (5분 안 또는 3정류장 안).
  • 카드를 펼치면 정보 출처(안동시 버스정보시스템 / 국토교통부 TAGO)가 보여요. 새 권한 없음.
  • v30b를 쓰고 있어도 도착 시간은 이미 나와요(서버 쪽 변경). v32b는 출처 표시만 바로잡은 판이에요.

v30 새로워진 점 · 버스 키 없이 바로

  • 이제 키를 넣지 않아도 진짜 버스 정보가 나와요. 뉴니버스 중계 서버가 국토교통부 TAGO에서 받아 전해 줘요. ⚙ 설정 › 위치 › 가까운 정류장 버스 알림만 켜면 돼요.
  • 자주 타는 버스: 같은 화면에 113, 순환1, 급행3처럼 적으면 카드에 그 버스만 보여요. 카드의 ★ 자주를 누르면 모든 노선이 보여요. 자주 타는 버스가 3정류장 안이나 5분 안으로 오면 홈 위쪽에 살짝 알려줘요. 이 폰에만 저장되고 홈 백업 파일에도 들어가요.
  • 도착 시간을 주지 않는 노선은 ‘0분’ 대신 ‘시간 정보 없음’으로 보여줘요. (안동은 v31부터 시간이 나와요.)
  • 가장 가까운 정류장에 오는 버스가 없으면 200m 안 다음 정류장(길 건너편 등)도 한 번 더 봐요.
  • 새 권한 없음. 위치는 전처럼 기능을 켤 때만 물어봐요.

v29 새로워진 점 · 꼭 필요한 것들

  • 알림 배지: ⚙ 설정 › 알림 › 앱 아이콘 배지를 숫자 또는 점으로 켜면 아이콘에 안 읽은 알림이 보여요(처음엔 꺼짐). 아이콘을 길게 누르면 최근 알림이 보이고, 누르면 그 알림이 열려요. 알림 내용은 폰 밖으로 나가지 않아요.
  • 진짜 빠른 설정: 손전등은 바로 켜고 꺼요. 와이파이·블루투스·모바일 데이터·비행기 모드·위치·절전은 안드로이드가 앱이 직접 못 바꾸게 막아 두어서, 지금 상태를 보여주고 누르면 폰 설정 창을 열어요. 자동 회전·폰 밝기·방해 금지는 처음 한 번 허용하면 바로 바뀌어요. 소리는 소리 ↔ 진동.
  • 홈 백업·복원: ⚙ 설정 › 계정 및 백업. 홈 배치·폴더·위젯·설정을 파일로 저장하고 불러와요(새 권한 없음). 자동 백업 1개도 따로 남아요. 폰 위젯은 다른 폰에선 다시 놓아야 할 수 있어요.
  • 통합 검색: 앱 + 뉴니버스 설정 + 안드로이드 설정 + 연락처(검색 화면의 ‘연락처도 찾기’를 켤 때만 권한을 물어봐요). 초성 검색, 연락처는 바로 전화·문자.
  • 최근 쓴 앱: 안드로이드는 홈 앱에게 ‘진짜 최근 앱 목록’을 주지 않아요. 그래서 ‘최근 앱’ 단추는 뉴니버스에서 연 앱을 보여줘요. 추가판(화면 끄기 켠 상태)은 ‘폰의 최근 앱 화면’ 단추로 진짜 최근 앱 화면도 열 수 있어요.
  • 고친 것: 보자기 테마에서 설정 상자가 어둡던 것, 아이콘이 4줄일 때 버스 카드가 아래 이름을 가리던 것.
폰에서 직접 허용할 것 (쓰고 싶은 것만)
· 알림 배지: 설정 › 알림 › 알림 접근 › 뉴니버스 알림 배지 켜기. 회색으로 막혀 있으면 먼저 설정 › 애플리케이션 › 뉴니버스 › ⋮ › 제한된 설정 허용(안드로이드 13 이상, 직접 깐 앱).
· 자동 회전·폰 밝기: ‘시스템 설정 변경’ 허용 · 방해 금지: ‘방해 금지 접근’ 허용 (타일을 누르면 안내해요)
· 연락처·위치: 기능을 켤 때 뜨는 창에서 허용

v28 새로워진 점 · 가까운 정류장 버스

  • ⚙ 설정 › 위치 › 가까운 정류장 버스 알림을 켜면, 정류장 200m 안에 갔을 때 홈 화면 아래에 몇 번 버스가 몇 분 뒤, 몇 정류장 전인지 카드가 모래처럼 모이며 떠올라요. 멀어지면 흩어져요. 카드를 누르면 더 많이 보여요.
  • (v30부터 키가 필요 없어요. 키 칸은 시험용 설정 안으로 옮겼어요.)
  • 새 권한: 위치. 기능을 켜고 키가 있을 때만 한 번 물어봐요. ‘대략적인 위치’만 허락하면 정류장이 잘 안 맞을 수 있어요(‘정확한 위치’ 권장). 뉴니버스 화면이 보일 때만 위치를 읽고(정류장 근처 30초, 그 밖 60초마다), 다른 앱을 쓰거나 화면이 꺼져 있을 땐 읽지 않아요.
  • 정보 출처: 국토교통부 TAGO. TAGO에 들어 있지 않은 지역은 정류장을 못 찾을 수 있어요.
아직 실제 폰에서 처음 확인하는 기능이에요. 위치 허락 창, 정류장 찾기, 도착 시간이 이상하면 알려 주세요.

v27 새로워진 점 · 제스처 모드

  • ⚙ 설정 › 디스플레이 › 내비게이션 바 › 스와이프 제스처로 바꾸면 뒤로·홈·최근 단추가 있던 자리만큼 독이 아래로 내려와 얇은 손잡이 바로 위에 와요. 바꾸면 독이 부드럽게 미끄러져 내려가요.
  • 폰이 이미 제스처 탐색을 쓰고 있으면 처음부터 제스처 모드로 맞춰져요. (직접 고르면 그 선택을 따라요)

v26 새로워진 점 · 바닥 정리

  • 독을 내비게이션 바 바로 위까지 내렸어요. (누르는 영역은 겹치지 않게 조금 띄웠어요)

v25 새로워진 점 · 독

  • 아래 독의 가로 판과 아이콘 틀을 없앴어요. 전화 · 문자 · 인터넷 · 주소록 그림만 배경 위에 떠 있어요.
  • 밝은 배경(벚꽃 등)에서도 잘 보이게 그림자와 은은한 빛을 넣었고, 누르면 살짝 빛나요.
  • 독에 다른 앱을 넣으면 그 앱의 원래 아이콘이 틀 없이 그대로 보여요. 홈 화면 아이콘은 그대로예요.

v24 새로워진 점 · 디자인 정리

  • 메뉴·빠른 설정·편집 막대·대화상자·검색창 곳곳의 이모지 아이콘을 뉴니버스 선 아이콘으로 바꿨어요.
  • 색은 하늘빛→보랏빛 한 가지 강조색, 판은 어두운 유리, 모서리·글꼴 굵기를 하나로 맞췄어요. (주황 단추가 없어졌어요)
  • 밝기·소리 같은 슬라이더, 켜기/끄기 스위치, 검색창이 기본 안드로이드 모양 대신 뉴니버스 모양이에요.
  • 찾는 앱이 없을 때 안내, 삭제 같은 위험한 메뉴는 붉은색으로 구분돼요.

v23 새로워진 점 · 위젯

  • 홈 빈 곳을 길게 누르면 ‘위젯 추가’가 나와요. (홈 화면 편집 막대의 🧩 위젯으로도 돼요.)
  • 폰에 깔린 앱들의 진짜 위젯(캘린더, 메모, 음악 등)을 미리보기와 크기와 함께 골라 놓을 수 있어요. 처음 한 번은 ‘뉴니버스가 위젯을 만들도록 허용할까요?’ 창이 뜰 수 있어요 → 허용(항상 허용 체크). 설정이 필요한 위젯은 그 앱의 설정 화면이 이어서 떠요.
  • 뉴니버스 전용 위젯 3개: 큰 시계·날짜, 배터리, 저장공간. 모두 폰의 진짜 값을 보여 줘요. (가짜 날씨는 뺐어요.)
  • 위젯을 길게 누르면 크기 바꾸기 · 옮기기 · 위젯 설정 · 위젯 삭제. 배치는 저장돼서 다시 켜도 그대로예요.
  • 화면을 넘기면 위젯도 그림으로 바뀌어 모래알로 함께 흩어져요. 독과 아래 막대는 그대로예요.
  • 새 권한은 하나도 늘지 않았어요. (인터넷 · 진동 · 배경화면 3개 그대로)
아직 첫 시험이에요: 위젯 위에서 옆으로 밀어 넘기기, 위젯 그림 스냅샷, 허용 창은 실제 폰에서 처음 확인하는 기능이에요. 어색하면 알려 주세요. 위젯을 끌어 옮기려면 길게 눌러 옮기기를 고른 뒤 편집 화면에서 끌어요. ‘클래식’ 이외의 화면 스타일에서는 위젯이 잠시 숨겨져요.

v22 새로워진 점 · 화면 넘김

  • 폰 속도를 처음에 잠깐 재고, 넘길 때마다 끊김을 살펴 모래알 수·해상도를 저절로 맞춰요.
  • 넘기는 동안에는 움직이는 배경을 잠깐 멈춰서 모래알에 힘을 몰아줘요.
  • ⚙ 설정 › 디스플레이 › 전환 품질에서 자동(기본) · 부드러움 우선 · 화질 우선을 고를 수 있어요. 아직 끊기면 ‘부드러움 우선’을 눌러 보세요.

1. 설치하기

  1. 이 폰의 크롬(또는 삼성 인터넷)에서 위 단추를 눌러 내려받아요.
  2. ‘이 유형의 파일은 기기에 해를 끼칠 수 있습니다’가 나오면 다운로드를 눌러요.
  3. 다운로드 알림이나 내 파일 › 다운로드에서 newniverse-launcher-v46.apk를 눌러요.
  4. ‘출처를 알 수 없는 앱’ 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아와요.
  5. 설치를 눌러요. ‘Play 프로텍트’ 안내가 나오면 세부정보 › 무시하고 설치(또는 ‘그래도 설치’)를 눌러요. 구글 스토어를 거치지 않은 시험판이라 나오는 안내예요.
폰에 따라 ‘무시하고 설치’ 단추가 아예 안 보이고 ‘앱이 설치되지 않았습니다’로 끝날 수 있어요. 그럴 땐 아래 7. 그래도 막힐 때를 보세요.

2. 기본 홈 앱으로 정하기

  1. 폰 설정 › 애플리케이션 › 기본 앱 선택 › 홈 화면(또는 ‘홈 앱’)으로 가요.
  2. 뉴니버스를 골라요.
  3. 홈 단추를 누르면 뉴니버스가 떠요. (설치 직후 홈 단추를 누르면 ‘홈 앱 고르기’ 창이 바로 뜰 수도 있어요. 그때 뉴니버스 → 항상.)
뉴니버스 안에서도 바꿀 수 있어요: 화면을 위에서 아래로 내려 ⚙ 설정 → 맨 위 기본 홈 앱.
갤럭시 S22+ 등 One UI 8(안드로이드 16): 기본 앱 › 홈 앱 목록에 뉴니버스가 안 보일 수 있어요. 그땐 이 길로 가요 → 설정 › 애플리케이션 › 뉴니버스를 눌러 앱 정보 화면을 열고, 아래쪽 ‘홈 화면’ 줄(현재 ‘One UI 홈’)을 눌러 뉴니버스를 고르면 바로 바뀌어요. 앱을 길게 눌러 ‘앱 정보’로 들어가도 같아요.
뉴니버스 문자를 같이 쓸 때는 문자 앱을 먼저 설치한 뒤, 런처를 같은 파일로 한 번 더(덮어) 설치해 주세요. 그래야 문자 속 할 일 카드가 연결돼요. 설정·데이터는 그대로예요. 홈에 「런처를 다시 설치해 주세요」 카드가 뜨면 이 뜻이에요.

3. 두 번 톡톡

  1. 앱 없는 홈(우주)에서는 빈 곳을 톡톡 두 번 누르면 말로 찾기가 시작돼요. 예전 아이콘 홈에서는 화면이 검게 어두워져요(추가판은 진짜 끄기). 어두운 화면은 아무 데나 누르면 다시 밝아져요.
  2. 기본판은 접근성 권한을 쓰지 않아서 진짜로 끄지는 못해요. 진짜 끄기는 아래 추가판에 있어요.
두 번 톡톡 기능은 뉴니버스 ⚙ 설정 › 유용한 기능에서 켜고 끌 수 있어요.

4. 잠금화면 배경도 바꾸기

  1. 뉴니버스에서 화면을 위에서 아래로 내려 ⚙ 설정 › 배경화면 및 스타일로 가요.
  2. 마음에 드는 배경(내 사진 합성도 돼요)을 고르고 🔒 잠금화면에도 적용을 눌러요.
  3. 미리보기를 보고 잠금화면에 적용을 누르면 끝! 화면을 껐다 켜면 바뀐 잠금화면이 보여요.
움직이는 배경은 잠금화면에는 멈춘 그림으로 들어가요. 홈 화면 배경은 그대로예요.

5. 홈 화면 꾸미기 (v21 새 기능)

  • 아이콘을 길게 누르면 메뉴가 떠요: 앱 정보 · 삭제 · 홈에서 제거 · 독에 추가 · 홈 편집. (기본판에서 ‘삭제’는 앱 정보 화면이 열리고, 거기서 삭제를 누르면 돼요)
  • 길게 누른 채 끌면 아이콘을 옮길 수 있어요. 화면 왼쪽·오른쪽 끝에 잠깐 멈추면 옆 화면으로 넘어가요. 맨 끝에서 더 밀면 새 화면이 생겨요.
  • 아이콘을 다른 아이콘 위에 놓으면 폴더가 생겨요. 폴더를 열고 이름을 누르면 이름을 바꿀 수 있고, 폴더 안 앱을 길게 누르면 폴더에서 빼기가 돼요.
  • 빈 곳을 길게 누르면 편집 모드예요. 위의 ＋ 화면 추가 / 🗑 이 화면 지우기 / 완료를 쓰세요. 아래 독은 최대 4개예요.
  • 전체 앱 검색은 초성도 돼요 (예: ㅋㅋㅇ → 카카오톡). 앱은 가나다순이고, 길게 누르면 홈에 추가하거나 끌어서 바로 놓을 수 있어요.
  • 새로 깐 앱은 저절로 홈 빈자리에 놓이고, 지운 앱은 저절로 사라져요. (⚙ 설정 › 홈 화면 › ‘새 앱을 홈 화면에 추가’로 끌 수 있어요)
배치·폴더·설정은 폰 안에 저장돼서 껐다 켜도 그대로예요. 처음 배치로 돌리려면 ⚙ 설정 › 홈 화면 › 홈 배치 처음으로. 예전 버전 위에 그냥 설치하면 업데이트돼요.

6. 원래 홈으로 되돌리기

  1. 폰 설정 › 애플리케이션 › 기본 앱 선택 › 홈 화면에서 One UI 홈을 고르면 바로 원래대로 돌아가요.
  2. 뉴니버스를 아예 지우려면: 설정 › 애플리케이션 › 뉴니버스 › 삭제. 지우면 자동으로 원래 홈으로 돌아가요.
뉴니버스 안에서는 화면을 내려 📱 폰 설정 단추를 누르면 원래 안드로이드 설정이 열려요.

7. 그래도 막힐 때 · 추가판 (진짜 화면 끄기 포함)

추가판은 화면을 진짜로 끄려고 접근성 권한을 써요. 그래서 Play 프로텍트가 “기기 보호를 위해 앱 차단됨 – 민감한 정보에 대한 액세스 권한을 요청할 수 있습니다”라며 막을 수 있고, 이때는 ‘무시하고 설치’ 단추가 안 보일 수 있어요. 꼭 필요할 때만 쓰세요.
⬇ 추가판 내려받기 (화면 끄기 포함)
  1. Play 스토어 앱 → 오른쪽 위 내 프로필 동그라미 → Play 프로텍트.
  2. 오른쪽 위 ⚙ 톱니 → ‘Play 프로텍트로 앱 검사’를 끄기. (확인 창이 뜨면 끄기)
  3. 내려받은 APK를 눌러 설치해요. (기본판이 깔려 있으면 그대로 업데이트돼요. 같은 서명이에요)
  4. 설치가 끝나면 같은 곳에서 ‘Play 프로텍트로 앱 검사’를 다시 켜요. 꼭이요!
  5. 뉴니버스 빈 곳을 두 번 톡톡 → 접근성 설정 열기 → 설치된 앱 › 뉴니버스 화면 끄기 켜기 · 허용.
기본판도 막히면 위 1~4번(검사 잠시 끄기 → 설치 → 다시 켜기)을 똑같이 하면 돼요. 접근성 권한은 ‘화면 끄기’에만 쓰고, 화면 내용이나 입력한 글자는 읽지도 저장하지도 않아요.

쓰는 법 요약

  • 옆으로 밀기: 다음 화면 (모래바람 전환)
  • 위에서 아래로: 빠른 설정 (손전등은 진짜로 켜져요, 와이파이·블루투스는 폰 설정 창이 열려요)
  • 가운데에서 위로: 전체 앱 (설치된 모든 앱, 누르면 실행)
  • 빈 곳 톡톡 두 번: 화면 어둡게 (추가판은 진짜 끄기)
  • 아이콘 길게 누르기: 메뉴 · 옮기기 · 폴더 만들기
  • 맨 아래 뒤로 · 홈 · 최근 앱 (설정 › 디스플레이 › 내비게이션 바에서 제스처로 바꿀 수 있어요)
느린 폰이나 그래픽 가속이 없는 폰에서는 가벼운 모드가 저절로 켜져 모래알 수를 줄여요. ⚙ 설정 › 디스플레이 › 가벼운 모드에서 직접 켜고 끌 수도 있어요.
