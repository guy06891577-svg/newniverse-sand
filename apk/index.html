버전 0.32b 기본판 · 뉴니버스 고정 서명 · 버스 카드 고정 (하단/상단)
⬇ 기본판 내려받기 (약 22MB)
대부분은 이 기본판이면 돼요. 민감한 권한(접근성 등)을 하나도 쓰지 않아서 Play 프로텍트에 막힐 일이 훨씬 적어요. 쓰는 권한은 인터넷 · 진동 · 배경화면 바꾸기, v28부터 위치(버스 알림을 켤 때만), v29부터 연락처(검색에서 연락처를 켤 때만)와 아래 v29의 ‘직접 허용’ 항목들이에요.
두 번 톡톡 하면 화면을 검게 어둡게만 해요. 진짜로 화면을 끄는 기능은 나중에 추가판에서 드려요.
예전 시험판 v21 이하(처음 받은 시험판)가 깔려 있으면 서명이 달라서 위에 덮어 깔 수 없어요. 먼저 지우고 깔아 주세요: 설정 › 애플리케이션 › 뉴니버스 › 삭제. 지우면 홈 배치·설정도 처음으로 돌아가요.
v21b ~ v31b(기본판/추가판)를 깔았던 폰은 지우지 않고 그대로 깔면 업데이트돼요. 처음 까는 폰이면 상관없어요.

v32 새로워진 점 · 버스 카드 고정

  • 버스 알림을 켜 두면 카드가 홈 화면 맨 아래, 독 바로 위에 붙어 있어요. 모든 홈 화면에서 같은 자리이고, 화면을 넘길 때도 모래처럼 흩어지지 않아요.
  • ⚙ 설정 › 위치 › 버스 카드 위치에서 하단(기본) / 상단(맨 위)을 고를 수 있어요. 하단은 누르면 위로, 상단은 아래로 펼쳐져요.
  • 아이콘 이름을 가리지 않게 아이콘 줄 간격을 그만큼 줄여요(아이콘 수와 배치는 그대로). 버스 알림을 끄면 원래 간격으로 돌아가요.
  • 근처에 정류장이 없을 땐 같은 자리에 ‘가까운 정류장이 없어요’가 작게 떠 있어요(누르면 위치 설정).

v31 새로워진 점 · 안동 버스 도착 시간

  • 안동도 이제 몇 분 뒤, 몇 정류장 전인지 나와요. 안동시가 공개한 안동시 버스정보시스템 정보를 뉴니버스 중계 서버가 받아 전해 줘요 (안동시 BIS 누리집의 ‘약 N분후 도착’과 같은 값). 그 서버가 안 되면 예전처럼 노선만 보여요.
  • 자주 타는 버스 알림도 안동에서 돼요 (5분 안 또는 3정류장 안).
  • 카드를 펼치면 정보 출처(안동시 버스정보시스템 / 국토교통부 TAGO)가 보여요. 새 권한 없음.
  • v30b를 쓰고 있어도 도착 시간은 이미 나와요(서버 쪽 변경). v32b는 출처 표시만 바로잡은 판이에요.

v30 새로워진 점 · 버스 키 없이 바로

  • 이제 키를 넣지 않아도 진짜 버스 정보가 나와요. 뉴니버스 중계 서버가 국토교통부 TAGO에서 받아 전해 줘요. ⚙ 설정 › 위치 › 가까운 정류장 버스 알림만 켜면 돼요.
  • 자주 타는 버스: 같은 화면에 113, 순환1, 급행3처럼 적으면 카드에 그 버스만 보여요. 카드의 ★ 자주를 누르면 모든 노선이 보여요. 자주 타는 버스가 3정류장 안이나 5분 안으로 오면 홈 위쪽에 살짝 알려줘요. 이 폰에만 저장되고 홈 백업 파일에도 들어가요.
  • 도착 시간을 주지 않는 노선은 ‘0분’ 대신 ‘시간 정보 없음’으로 보여줘요. (안동은 v31부터 시간이 나와요.)
  • 가장 가까운 정류장에 오는 버스가 없으면 200m 안 다음 정류장(길 건너편 등)도 한 번 더 봐요.
  • 새 권한 없음. 위치는 전처럼 기능을 켤 때만 물어봐요.

v29 새로워진 점 · 꼭 필요한 것들

  • 알림 배지: ⚙ 설정 › 알림 › 앱 아이콘 배지를 숫자 또는 점으로 켜면 아이콘에 안 읽은 알림이 보여요(처음엔 꺼짐). 아이콘을 길게 누르면 최근 알림이 보이고, 누르면 그 알림이 열려요. 알림 내용은 폰 밖으로 나가지 않아요.
  • 진짜 빠른 설정: 손전등은 바로 켜고 꺼요. 와이파이·블루투스·모바일 데이터·비행기 모드·위치·절전은 안드로이드가 앱이 직접 못 바꾸게 막아 두어서, 지금 상태를 보여주고 누르면 폰 설정 창을 열어요. 자동 회전·폰 밝기·방해 금지는 처음 한 번 허용하면 바로 바뀌어요. 소리는 소리 ↔ 진동.
  • 홈 백업·복원: ⚙ 설정 › 계정 및 백업. 홈 배치·폴더·위젯·설정을 파일로 저장하고 불러와요(새 권한 없음). 자동 백업 1개도 따로 남아요. 폰 위젯은 다른 폰에선 다시 놓아야 할 수 있어요.
  • 통합 검색: 앱 + 뉴니버스 설정 + 안드로이드 설정 + 연락처(검색 화면의 ‘연락처도 찾기’를 켤 때만 권한을 물어봐요). 초성 검색, 연락처는 바로 전화·문자.
  • 최근 쓴 앱: 안드로이드는 홈 앱에게 ‘진짜 최근 앱 목록’을 주지 않아요. 그래서 ‘최근 앱’ 단추는 뉴니버스에서 연 앱을 보여줘요. 추가판(화면 끄기 켠 상태)은 ‘폰의 최근 앱 화면’ 단추로 진짜 최근 앱 화면도 열 수 있어요.
  • 고친 것: 보자기 테마에서 설정 상자가 어둡던 것, 아이콘이 4줄일 때 버스 카드가 아래 이름을 가리던 것.
폰에서 직접 허용할 것 (쓰고 싶은 것만)
· 알림 배지: 설정 › 알림 › 알림 접근 › 뉴니버스 알림 배지 켜기. 회색으로 막혀 있으면 먼저 설정 › 애플리케이션 › 뉴니버스 › ⋮ › 제한된 설정 허용(안드로이드 13 이상, 직접 깐 앱).
· 자동 회전·폰 밝기: ‘시스템 설정 변경’ 허용 · 방해 금지: ‘방해 금지 접근’ 허용 (타일을 누르면 안내해요)
· 연락처·위치: 기능을 켤 때 뜨는 창에서 허용

v28 새로워진 점 · 가까운 정류장 버스

  • ⚙ 설정 › 위치 › 가까운 정류장 버스 알림을 켜면, 정류장 200m 안에 갔을 때 홈 화면 아래에 몇 번 버스가 몇 분 뒤, 몇 정류장 전인지 카드가 모래처럼 모이며 떠올라요. 멀어지면 흩어져요. 카드를 누르면 더 많이 보여요.
  • (v30부터 키가 필요 없어요. 키 칸은 시험용 설정 안으로 옮겼어요.)
  • 새 권한: 위치. 기능을 켜고 키가 있을 때만 한 번 물어봐요. ‘대략적인 위치’만 허락하면 정류장이 잘 안 맞을 수 있어요(‘정확한 위치’ 권장). 뉴니버스 화면이 보일 때만 위치를 읽고(정류장 근처 30초, 그 밖 60초마다), 다른 앱을 쓰거나 화면이 꺼져 있을 땐 읽지 않아요.
  • 정보 출처: 국토교통부 TAGO. TAGO에 들어 있지 않은 지역은 정류장을 못 찾을 수 있어요.
아직 실제 폰에서 처음 확인하는 기능이에요. 위치 허락 창, 정류장 찾기, 도착 시간이 이상하면 알려 주세요.

v27 새로워진 점 · 제스처 모드

  • ⚙ 설정 › 디스플레이 › 내비게이션 바 › 스와이프 제스처로 바꾸면 뒤로·홈·최근 단추가 있던 자리만큼 독이 아래로 내려와 얇은 손잡이 바로 위에 와요. 바꾸면 독이 부드럽게 미끄러져 내려가요.
  • 폰이 이미 제스처 탐색을 쓰고 있으면 처음부터 제스처 모드로 맞춰져요. (직접 고르면 그 선택을 따라요)

v26 새로워진 점 · 바닥 정리

  • 화면 아래 페이지 점 3개를 없앴어요.
  • 독을 내비게이션 바 바로 위까지 내렸어요. (누르는 영역은 겹치지 않게 조금 띄웠어요)

v25 새로워진 점 · 독

  • 아래 독의 가로 판과 아이콘 틀을 없앴어요. 전화 · 문자 · 인터넷 · 주소록 그림만 배경 위에 떠 있어요.
  • 밝은 배경(벚꽃 등)에서도 잘 보이게 그림자와 은은한 빛을 넣었고, 누르면 살짝 빛나요.
  • 독에 다른 앱을 넣으면 그 앱의 원래 아이콘이 틀 없이 그대로 보여요. 홈 화면 아이콘은 그대로예요.

v24 새로워진 점 · 디자인 정리

  • 메뉴·빠른 설정·편집 막대·대화상자·검색창 곳곳의 이모지 아이콘을 뉴니버스 선 아이콘으로 바꿨어요.
  • 색은 하늘빛→보랏빛 한 가지 강조색, 판은 어두운 유리, 모서리·글꼴 굵기를 하나로 맞췄어요. (주황 단추가 없어졌어요)
  • 밝기·소리 같은 슬라이더, 켜기/끄기 스위치, 검색창이 기본 안드로이드 모양 대신 뉴니버스 모양이에요.
  • 찾는 앱이 없을 때 안내, 삭제 같은 위험한 메뉴는 붉은색으로 구분돼요.

v23 새로워진 점 · 위젯

  • 홈 빈 곳을 길게 누르면 ‘위젯 추가’가 나와요. (홈 화면 편집 막대의 🧩 위젯으로도 돼요.)
  • 폰에 깔린 앱들의 진짜 위젯(캘린더, 메모, 음악 등)을 미리보기와 크기와 함께 골라 놓을 수 있어요. 처음 한 번은 ‘뉴니버스가 위젯을 만들도록 허용할까요?’ 창이 뜰 수 있어요 → 허용(항상 허용 체크). 설정이 필요한 위젯은 그 앱의 설정 화면이 이어서 떠요.
  • 뉴니버스 전용 위젯 3개: 큰 시계·날짜, 배터리, 저장공간. 모두 폰의 진짜 값을 보여 줘요. (가짜 날씨는 뺐어요.)
  • 위젯을 길게 누르면 크기 바꾸기 · 옮기기 · 위젯 설정 · 위젯 삭제. 배치는 저장돼서 다시 켜도 그대로예요.
  • 화면을 넘기면 위젯도 그림으로 바뀌어 모래알로 함께 흩어져요. 독과 아래 막대는 그대로예요.
  • 새 권한은 하나도 늘지 않았어요. (인터넷 · 진동 · 배경화면 3개 그대로)
아직 첫 시험이에요: 위젯 위에서 옆으로 밀어 넘기기, 위젯 그림 스냅샷, 허용 창은 실제 폰에서 처음 확인하는 기능이에요. 어색하면 알려 주세요. 위젯을 끌어 옮기려면 길게 눌러 옮기기를 고른 뒤 편집 화면에서 끌어요. ‘클래식’ 이외의 화면 스타일에서는 위젯이 잠시 숨겨져요.

v22 새로워진 점 · 화면 넘김

  • 폰 속도를 처음에 잠깐 재고, 넘길 때마다 끊김을 살펴 모래알 수·해상도를 저절로 맞춰요.
  • 넘기는 동안에는 움직이는 배경을 잠깐 멈춰서 모래알에 힘을 몰아줘요.
  • ⚙ 설정 › 디스플레이 › 전환 품질에서 자동(기본) · 부드러움 우선 · 화질 우선을 고를 수 있어요. 아직 끊기면 ‘부드러움 우선’을 눌러 보세요.

1. 설치하기

  1. 이 폰의 크롬(또는 삼성 인터넷)에서 위 단추를 눌러 내려받아요.
  2. ‘이 유형의 파일은 기기에 해를 끼칠 수 있습니다’가 나오면 다운로드를 눌러요.
  3. 다운로드 알림이나 내 파일 › 다운로드에서 newniverse-launcher-v32b.apk를 눌러요.
  4. ‘출처를 알 수 없는 앱’ 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아와요.
  5. 설치를 눌러요. ‘Play 프로텍트’ 안내가 나오면 세부정보 › 무시하고 설치(또는 ‘그래도 설치’)를 눌러요. 구글 스토어를 거치지 않은 시험판이라 나오는 안내예요.
폰에 따라 ‘무시하고 설치’ 단추가 아예 안 보이고 ‘앱이 설치되지 않았습니다’로 끝날 수 있어요. 그럴 땐 아래 7. 그래도 막힐 때를 보세요.

2. 기본 홈 앱으로 정하기

  1. 폰 설정 › 애플리케이션 › 기본 앱 선택 › 홈 화면(또는 ‘홈 앱’)으로 가요.
  2. 뉴니버스를 골라요.
  3. 홈 단추를 누르면 뉴니버스가 떠요. (설치 직후 홈 단추를 누르면 ‘홈 앱 고르기’ 창이 바로 뜰 수도 있어요. 그때 뉴니버스 → 항상.)
뉴니버스 안에서도 바꿀 수 있어요: 화면을 위에서 아래로 내려 ⚙ 설정 → 맨 위 기본 홈 앱.

3. 두 번 톡톡 (기본판은 어둡게만)

  1. 홈 화면 빈 곳을 톡톡 두 번 누르면 화면이 검게 어두워져요. 아무 데나 누르면 다시 밝아져요.
  2. 기본판은 접근성 권한을 쓰지 않아서 진짜로 끄지는 못해요. 진짜 끄기는 아래 추가판에 있어요.
두 번 톡톡 기능은 뉴니버스 ⚙ 설정 › 유용한 기능에서 켜고 끌 수 있어요.

4. 잠금화면 배경도 바꾸기

  1. 뉴니버스에서 화면을 위에서 아래로 내려 ⚙ 설정 › 배경화면 및 스타일로 가요.
  2. 마음에 드는 배경(내 사진 합성도 돼요)을 고르고 🔒 잠금화면에도 적용을 눌러요.
  3. 미리보기를 보고 잠금화면에 적용을 누르면 끝! 화면을 껐다 켜면 바뀐 잠금화면이 보여요.
움직이는 배경은 잠금화면에는 멈춘 그림으로 들어가요. 홈 화면 배경은 그대로예요.

5. 홈 화면 꾸미기 (v21 새 기능)

  • 아이콘을 길게 누르면 메뉴가 떠요: 앱 정보 · 삭제 · 홈에서 제거 · 독에 추가 · 홈 편집. (기본판에서 ‘삭제’는 앱 정보 화면이 열리고, 거기서 삭제를 누르면 돼요)
  • 길게 누른 채 끌면 아이콘을 옮길 수 있어요. 화면 왼쪽·오른쪽 끝에 잠깐 멈추면 옆 화면으로 넘어가요. 맨 끝에서 더 밀면 새 화면이 생겨요.
  • 아이콘을 다른 아이콘 위에 놓으면 폴더가 생겨요. 폴더를 열고 이름을 누르면 이름을 바꿀 수 있고, 폴더 안 앱을 길게 누르면 폴더에서 빼기가 돼요.
  • 빈 곳을 길게 누르면 편집 모드예요. 위의 ＋ 화면 추가 / 🗑 이 화면 지우기 / 완료를 쓰세요. 아래 독은 최대 4개예요.
  • 전체 앱 검색은 초성도 돼요 (예: ㅋㅋㅇ → 카카오톡). 앱은 가나다순이고, 길게 누르면 홈에 추가하거나 끌어서 바로 놓을 수 있어요.
  • 새로 깐 앱은 저절로 홈 빈자리에 놓이고, 지운 앱은 저절로 사라져요. (⚙ 설정 › 홈 화면 › ‘새 앱을 홈 화면에 추가’로 끌 수 있어요)
배치·폴더·설정은 폰 안에 저장돼서 껐다 켜도 그대로예요. 처음 배치로 돌리려면 ⚙ 설정 › 홈 화면 › 홈 배치 처음으로. 예전 버전 위에 그냥 설치하면 업데이트돼요.

6. 원래 홈으로 되돌리기

  1. 폰 설정 › 애플리케이션 › 기본 앱 선택 › 홈 화면에서 One UI 홈을 고르면 바로 원래대로 돌아가요.
  2. 뉴니버스를 아예 지우려면: 설정 › 애플리케이션 › 뉴니버스 › 삭제. 지우면 자동으로 원래 홈으로 돌아가요.
뉴니버스 안에서는 화면을 내려 📱 폰 설정 단추를 누르면 원래 안드로이드 설정이 열려요.

7. 그래도 막힐 때 · 추가판 (진짜 화면 끄기 포함)

추가판은 화면을 진짜로 끄려고 접근성 권한을 써요. 그래서 Play 프로텍트가 “기기 보호를 위해 앱 차단됨 – 민감한 정보에 대한 액세스 권한을 요청할 수 있습니다”라며 막을 수 있고, 이때는 ‘무시하고 설치’ 단추가 안 보일 수 있어요. 꼭 필요할 때만 쓰세요.
⬇ 추가판 내려받기 (화면 끄기 포함)
  1. Play 스토어 앱 → 오른쪽 위 내 프로필 동그라미 → Play 프로텍트.
  2. 오른쪽 위 ⚙ 톱니 → ‘Play 프로텍트로 앱 검사’를 끄기. (확인 창이 뜨면 끄기)
  3. 내려받은 APK를 눌러 설치해요. (기본판이 깔려 있으면 그대로 업데이트돼요. 같은 서명이에요)
  4. 설치가 끝나면 같은 곳에서 ‘Play 프로텍트로 앱 검사’를 다시 켜요. 꼭이요!
  5. 뉴니버스 빈 곳을 두 번 톡톡 → 접근성 설정 열기 → 설치된 앱 › 뉴니버스 화면 끄기 켜기 · 허용.
기본판도 막히면 위 1~4번(검사 잠시 끄기 → 설치 → 다시 켜기)을 똑같이 하면 돼요. 접근성 권한은 ‘화면 끄기’에만 쓰고, 화면 내용이나 입력한 글자는 읽지도 저장하지도 않아요.

쓰는 법 요약

  • 옆으로 밀기: 다음 화면 (모래바람 전환)
  • 위에서 아래로: 빠른 설정 (손전등은 진짜로 켜져요, 와이파이·블루투스는 폰 설정 창이 열려요)
  • 가운데에서 위로: 전체 앱 (설치된 모든 앱, 누르면 실행)
  • 빈 곳 톡톡 두 번: 화면 어둡게 (추가판은 진짜 끄기)
  • 아이콘 길게 누르기: 메뉴 · 옮기기 · 폴더 만들기
  • 맨 아래 뒤로 · 홈 · 최근 앱 (설정 › 디스플레이 › 내비게이션 바에서 제스처로 바꿀 수 있어요)
느린 폰이나 그래픽 가속이 없는 폰에서는 가벼운 모드가 저절로 켜져 모래알 수를 줄여요. ⚙ 설정 › 디스플레이 › 가벼운 모드에서 직접 켜고 끌 수도 있어요.
