# 뉴니버스 문자 v1 (시험판) 설치 방법
안내 페이지: https://guy06891577-svg.github.io/newniverse-sand/apk/sms.html
내려받기: https://guy06891577-svg.github.io/newniverse-sand/apk/newniverse-sms-v1-test.apk
패키지 kr.newniverse.sms · 버전 1-test (versionCode 1) · 런처·전화와 같은 뉴니버스 릴리스 서명

1. Play 프로텍트 검사 잠시 끄기 → 내려받아 설치 → 다시 켜기.
2. 뉴니버스 문자 열기 → SMS·연락처·알림 허용.
   허용 창이 안 뜨면(제한된 설정): 앱 안내의 "앱 정보 열기" → ⋮ → "제한된 설정 허용" → 돌아와 "다시 시도".
3. (v1은 권장 안 함) 기본 문자 앱: 목록 ⋮ → "기본 문자 앱으로 설정". 되돌리기: 설정 › 애플리케이션 › 기본 앱 선택 › SMS 앱 › 메시지.

권한: READ_SMS(목록·대화·검색), SEND_SMS(보내기), RECEIVE_SMS(새 문자 알림), RECEIVE_MMS·RECEIVE_WAP_PUSH(기본 앱 자격),
READ_CONTACTS(이름 표시·받는 사람 찾기), POST_NOTIFICATIONS, VIBRATE. 인터넷 권한 없음(문자는 폰 밖으로 나가지 않음).
기본 SMS 앱 자격(ROLE_SMS): SMS_DELIVER 리시버(BROADCAST_SMS), WAP_PUSH_DELIVER 리시버(BROADCAST_WAP_PUSH, application/vnd.wap.mms-message),
RESPOND_VIA_MESSAGE 서비스(SEND_RESPOND_VIA_MESSAGE), SEND/SENDTO 액티비티(sms·smsto·mms·mmsto).
기본 앱일 때: 받은 문자를 직접 저장(Inbox), 보낸 문자는 Outbox → 결과에 따라 Sent/Failed. 기본 앱이 아닐 때: 저장은 원래 앱, 이 앱은 SMS_RECEIVED로 알림만.

v1 범위: 대화 목록(사람별 마지막 문자, 안 읽음, 주소록 이름), 목록 검색(이름·초성·번호·내용), 대화(말풍선·보내기·복사·실패 다시 보내기),
새 문자(주소록 검색), 새 문자 알림, 예전 MMS 사진·글 보기.
다음 판: MMS(사진·장문) 받기(WAP push → downloadMultimediaMessage → PDU 저장)와 보내기, 알림에서 바로 답장, 대화 삭제.

빌드: ./build.sh (aapt2 · javac 17 · d8 · zipalign · apksigner, android-34, minSdk 26). 서명 키와 비밀번호는 저장소에 없음.
