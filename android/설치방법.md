# 뉴니버스 런처 시험판 설치 방법
내려받기: https://guy06891577-svg.github.io/newniverse-sand/apk/
1. 폰 크롬에서 위 주소를 열고 "APK 내려받기"를 눌러요. (경고가 나오면 "다운로드")
2. 내 파일 › 다운로드 › newniverse-launcher-v47b-test.apk (기본판) 를 눌러요.
3. "출처를 알 수 없는 앱" 안내가 나오면 설정 → "이 출처 허용"을 켜고 돌아와요.
4. 설치를 눌러요. Play 프로텍트 경고는 "세부정보 › 무시하고 설치". 단추가 안 보이고 "앱이 설치되지 않았습니다"가 뜨면: Play 스토어 › 프로필 › Play 프로텍트 › ⚙ › "Play 프로텍트로 앱 검사" 잠시 끄기 → 설치 → 다시 켜기.
5. 설정 › 애플리케이션 › 기본 앱 선택 › 홈 화면 › 뉴니버스 를 골라요.
   (갤럭시 S22+ One UI 8 등에서 홈 앱 목록에 뉴니버스가 안 보이면: 설정 › 애플리케이션 › 뉴니버스 › 앱 정보 화면의 '홈 화면' 줄 › 뉴니버스.)
   (뉴니버스 문자를 같이 쓰면: 문자 앱을 먼저 설치한 뒤 런처를 같은 파일로 한 번 덮어 설치해야 문자 카드가 연결돼요.)
되돌리기: 같은 곳에서 "One UI 홈"을 고르거나, 설정 › 애플리케이션 › 뉴니버스 › 삭제.

두 번 톡톡: 기본판은 화면을 검게 어둡게만 해요 (접근성 권한 없음). 진짜 끄기는 추가판(newniverse-launcher-v47b-test-plus.apk)에서만, 아래처럼 켜요.
추가판 화면 끄기 (처음 한 번만): 홈 빈 곳을 두 번 톡톡 → 안내 창의 "접근성 설정 열기" → 설치된 앱 › 뉴니버스 화면 끄기 → 켜기 · 허용 → 돌아와서 다시 톡톡. (안드로이드 9 이상, 화면 끄기에만 사용)
잠금화면 배경: 뉴니버스 설정 › 배경화면 및 스타일 › 🔒 잠금화면에도 적용 → 잠금화면에 적용. (움직이는 배경은 멈춘 그림으로 들어가요)
홈 꾸미기 (v21): 아이콘 길게 누르기 → 메뉴(앱 정보·삭제·홈에서 제거·독에 추가), 누른 채 끌어서 옮기기(화면 끝에서 멈추면 옆 화면), 아이콘 위에 놓으면 폴더, 빈 곳 길게 누르기 → 편집 모드(화면 추가·지우기). 전체 앱 검색은 초성(ㅋㅋㅇ)도 되고 가나다순. 새 앱은 저절로 홈에, 지운 앱은 저절로 사라져요. 배치는 껐다 켜도 그대로예요.

v22b부터 서명이 고정 릴리스 키예요. v21b~v33b 위에는 그냥 깔면 업데이트돼요. 예전 시험판(v21 이하, 디버그 서명)이 깔려 있으면 먼저 지우고 까세요. 기본판 ↔ 추가판은 같은 서명이라 위에 그냥 깔면 바뀌어요.
기본판 권한: 인터넷 · 진동 · 배경화면 설정 · 위치(v28, 버스 알림 켤 때만 요청) · 연락처(v29, 검색에서 켤 때만 요청) · 와이파이/네트워크 상태 읽기(자동) · 직접 허용: 알림 접근, 시스템 설정 변경, 방해 금지 접근. 추가판은 여기에 앱 삭제 요청 + 접근성(화면 끄기) 추가.

v22b: 화면 넘김 매끄럽게 (적응형 품질, 넘기는 동안 배경 멈춤). 설정 › 디스플레이 › 전환 품질 (자동/부드러움 우선/화질 우선).
처음 받은 v21 이하 디버그 시험판 위에는 덮어 깔 수 없어요 → 지우고 설치. v21b 위에는 그대로 업데이트.

v23b: 위젯. 홈 빈 곳 길게 누르기 › 위젯 추가. 폰 앱 위젯 + 뉴니버스 시계/배터리/저장공간. 위젯 길게 누르기 › 크기/옮기기/설정/삭제. 새 권한 없음.
v24b: 디자인 정리. 이모지 → 선 아이콘, 강조색 하나(하늘빛→보랏빛), 유리 판, 뉴니버스 모양 슬라이더/스위치/검색창.
v25b: 독의 가로 판·아이콘 틀 없앰. 선 그림만 (그림자+빛), 누르면 빛남. 설치 앱은 원래 아이콘 그대로.
v26b: 페이지 점 없앰, 독을 내비게이션 바 바로 위로.
v27b: 제스처 모드에서 독이 단추 줄 자리만큼 아래로(손잡이 바로 위). 폰 시스템 내비 방식·아래 제스처 영역을 읽어 반영.
v32b: 가까운 정류장 버스 도착 알림 (설정 › 위치). 새 권한: 위치(대략/정확). 키(공공데이터포털)를 넣으면 실제 TAGO 데이터, 없으면 예시 데이터.
v32b: 알림 배지(숫자/점, 길게 눌러 미리보기 · 알림 접근 허용 필요, 막히면 앱 정보 › ⋮ › 제한된 설정 허용), 진짜 빠른 설정(손전등 직접, 회전·밝기는 시스템 설정 변경 허용, 방해 금지는 방해 금지 접근 허용, 와이파이·BT·데이터·위치·절전은 상태 표시 + 설정 창), 홈 백업·복원(파일, 자동 백업 1개), 통합 검색(앱·설정·연락처, 초성), 최근 쓴 앱(뉴니버스에서 연 앱; 진짜 최근 앱 목록은 안드로이드가 홈 앱에 안 줌). 보자기 설정 상자 밝게, 4줄일 때 버스 카드 자리 고침.
v32b: 버스 도착 정보를 뉴니버스 중계 서버(https://newniverse-bus.guy0689.workers.dev)로 받아 키 입력 없이 동작. 자주 타는 버스(113·순환1·급행3, 카드 ★로 전체 보기, 3정류장/5분 안이면 홈 위쪽 알림, 백업 포함). 안동은 TAGO가 도착 시간을 0으로만 줘서 "시간 정보 없음"(노선만) 표시. 키 칸은 설정 › 위치 › 시험용 설정 안. 새 권한 없음.
v32b: 안동(37040)은 중계 서버가 안동시 버스정보시스템 공식 공개 API(data.go.kr 15057790, bus.andong.go.kr)에서 도착 시간(분)·남은 정류장을 받아 표시, 실패 시 TAGO. 자주 타는 버스 알림 안동에서도 동작. 앱은 출처 표시만 바뀜(서버 변경이라 v30b도 시간 표시됨). 새 권한 없음.
v32b: 버스 알림을 켜면 카드가 홈 하단(독 바로 위)에 고정, 모든 화면 같은 자리·전환 때 안 흩어짐. 설정 › 위치 › 버스 카드 위치 (하단 기본 / 상단). 하단은 위로, 상단은 아래로 펼침. 아이콘 줄 간격을 줄여 이름 안 가림(배치 그대로), 끄면 원래대로. 새 권한 없음.
v33b: 홈 시계에 미세먼지·초미세먼지(좋음·보통·나쁨·매우나쁨, 설정 › 위치 › 홈 시계에 미세먼지, 켤 때만 위치 권한, 30분마다 약 1km 단위). 출처 에어코리아(한국환경공단) via 중계 서버 /v1/air. 공공데이터포털 활용신청(한국환경공단_에어코리아_대기오염정보, 한국환경공단_에어코리아_측정소정보) 승인 전에는 "준비 중". 독 전화 아이콘은 뉴니버스 전화(kr.newniverse.phone)가 깔려 있으면 그 앱을 열고, 지우면 원래 전화 앱으로. 새 권한 없음.
v34b: 위치 허락이 이미 있으면 홈 시계 날씨·미세먼지를 처음 한 번 저절로 켬(직접 끈 경우 제외). 날씨 = 기상청 단기예보 조회서비스(data.go.kr 15084084, 초단기실황 기온·강수형태·습도 + 초단기예보 하늘상태) via 중계 서버 /v1/weather (격자별 30분 캐시), 신청 전에는 미세먼지만. 버스 고정 카드는 닫기 없음(누르면 펼치기/접기), 빈 카드 누르면 바로 다시 찾기, 떠 있는 카드는 닫기 두 번. 새 권한 없음.

v35b: 독에서 연락처(주소록) 제거 → 전화·메시지·인터넷 3개 균등 배치(궤도·모래언덕·보자기 포함). 기존 배치는 한 번만 빼고(S.dockNoCon), 직접 다시 넣으면 유지. 연락처 앱은 앱 서랍에 그대로. 첫 실행 때 독 저장이 빠지던 문제(saveLayout TDZ) 고침 — 뉴니버스 전화 독 전환도 껐다 켜도 유지.

v36b: 버스 카드에 방면(안동 BIS via의 종점, 중계 서버 dir 필드 · 순환/TAGO는 빈칸). 앱 삭제·설치·폴더 때 홈 전체 다시 배치 대신 softLayout(바뀐 그림만), 일시정지·길게 누르기 메뉴·확인 창에서 버스 카드 숨기지 않음. 첫 화면 안내가 아이콘 줄과 겹치면 숨기고 한 번만 알림.

v37b: 독 문자 칸 = 뉴니버스 문자(kr.newniverse.sms)가 깔려 있으면 그 앱(기본 문자 앱 지정과 무관, S.nvSmsDock 1회 전환, 지우면 원래 문자 앱 복귀, 직접 뺀 아이콘은 다시 넣지 않음). NVNative.sms()도 뉴니버스 문자 우선. <queries>에 kr.newniverse.sms. 독 최대 5개(DOCK_MAX=5, 꽉 차면 자리 표시 없음).

v38b: 앱 없는 홈(기본 켜짐, S.nh). 우주 그림(wallpapers/nh_cosmos.jpg, 4초 간격 미세 이동·화면 꺼지면 멈춤·절전 모드면 정지, 배경 WebGL 루프 정지) + 엄지 위치 입력칸 「무엇을 하실 건가요?」 + 마이크(SpeechRecognizer ko-KR, 기기 내 인식 우선, 누를 때만 듣기, RECORD_AUDIO는 처음 누를 때 요청). 독 없음(내비 바만). 글자·음성 같은 의도 엔진(앱 이름·초성·은행/입금/송금·사진·전화·문자·계산·설정·버스), 결과 칸은 기울지 않은 반듯한 4칸 격자 + 차례로 나타남. 제안어 2~3개, 아침 6:00~9:30 버스 카드 위쪽, 위로 밀기 = 최근 앱 별자리, 길게 누르기 메뉴(홈 화면 설정/모든 앱/예전 홈으로), 설정 스위치 「앱 없는 홈 (우주)」로 예전 홈. queries에 kr.newniverse.calc · kr.newniverse.settings · RecognitionService. versionCode 39.

v39b: 마이크는 폰 음성 인식 화면(RecognizerIntent.ACTION_RECOGNIZE_SPEECH, ko-KR, FREE_FORM, MAX_RESULTS 5, 안내 「무엇을 하실 건가요?」). 후보를 모두 의도 엔진에 넣어 가장 맞는 것을 고르고 입력칸에 들은 말을 보여 줌. 어미·군더더기(좀·해줘·해야겠다·찍어볼까·보여줘·켜줘·열어줘·걸어줘) 제거, 띄어쓰기 무시, 동의어(찰칵·돈 보내·버스 언제·전화 걸어·메시지 등). 앱 안 SpeechRecognizer는 그 화면을 못 열 때만(메인 스레드, ko-KR, RECORD_AUDIO 확인 후, 오류 코드별 한국어 안내). 칸 등장·퇴장·앱 열기는 v37b와 같은 bfxBurst 모래(모이기/흩어지기), CSS 계단 등장 제거. versionCode 40.

v40b: 앱 없는 홈 빈 곳 두 번 톡톡=말로 찾기(RecognizerIntent, 마이크와 동일, 물결·입력칸 빛 단서). 화면 끄기는 예전 홈만. 영어 앱을 한국어 발음·초성·가까운 말로 찾기(그록봇/ㄱㄹㅂ/그럭봇 등, NH_PRON+자모 거리). 잠금화면에서 검색창·제안 낱말 숨김, 바로가기와 안내 겹침 해소. 잠금 알림은 실제 NotificationListener만, 날씨는 실측(위치 없으면 안동). versionCode 41.

v41b: 앱 없는 홈 입력칸(글씨·마이크·두 번 톡톡 공통)으로 폰 설정 제어. 밝기(올려/내려/최대/최소/N%)·자동밝기·자동회전(WRITE_SETTINGS)·무음·방해금지(방해 금지 접근)는 런처가 직접(JS bridge ctl→Settings.System/AudioManager/NotificationManager), 진동·소리모드·손전등·미디어 볼륨은 허용 없이 직접. 와이파이·데이터·NFC·비행기는 Settings.Panel, 블루투스·위치·핫스팟은 시스템 설정 화면만 열기. 처음 필요할 때만 한국어 안내 후 허용 화면으로, 돌아오면 이어서 실행. 결과 유리 카드(슬라이더·되돌리기)→bfxBurst 모래로 우주 복귀. 제안어는 밤(21~5시)에 무음·밝기. versionCode 42.
