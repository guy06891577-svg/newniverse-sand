# 뉴니버스 전화 v3 (시험판) 설치 방법
안내 페이지: https://guy06891577-svg.github.io/newniverse-sand/apk/phone.html
내려받기: https://guy06891577-svg.github.io/newniverse-sand/apk/newniverse-phone-v3-test.apk
패키지 kr.newniverse.phone · 버전 3-test (versionCode 3, v1·v2 위에 덮어 설치) · 런처와 같은 뉴니버스 릴리스 서명

1. Play 스토어 › 프로필 › Play 프로텍트 › 톱니바퀴 › "Play 프로텍트로 앱 검사" 잠시 끄기.
2. 폰 크롬에서 내려받기 → 내 파일 › 다운로드 › newniverse-phone-v3-test.apk → (출처 허용) → 설치.
3. 설치 뒤 Play 프로텍트 검사를 다시 켜기.
4. 뉴니버스 전화 열기 → 전화·통화 기록·연락처·알림 권한 허용.
5. 기본 전화 앱 지정: 키패드 오른쪽 위 ⋮ → "기본 전화 앱으로 설정" → 뉴니버스 전화 → 기본으로 설정.
   "액세스가 거부됨"(제한된 설정) 창이 뜨면: 앱 안내의 "앱 정보 열기" → ⋮ → "제한된 설정 허용" → 돌아와 "다시 시도".
   (또는 설정 › 애플리케이션 › 기본 앱 선택 › 전화 앱 › 뉴니버스 전화)
되돌리기: 설정 › 애플리케이션 › 기본 앱 선택 › 전화 앱 › 전화. 앱을 지워도 자동으로 원래 앱으로 돌아가요.

권한: CALL_PHONE(바로 걸기), READ_CALL_LOG / WRITE_CALL_LOG(최근 통화 표시·삭제, 부재중 읽음 처리), READ_CONTACTS(이름·초성 검색),
POST_NOTIFICATIONS(수신·통화 중·부재중 알림), USE_FULL_SCREEN_INTENT(잠금 화면 위 수신 화면), VIBRATE, WAKE_LOCK(귀에 대면 화면 끄기).
역할: ROLE_DIALER(기본 전화 앱). 녹음 권한 없음, 인터넷 권한 없음(통화 기록·연락처는 폰 밖으로 나가지 않음).
긴급 전화(112·119 등)는 안드로이드가 항상 폰 기본 전화 앱으로 연결해요.

빌드: ./build.sh (aapt2 · javac 17 · d8 · zipalign · apksigner, android-34, minSdk 26). 서명 키와 비밀번호는 저장소에 없음.

v2: 최근 통화 위 큰 기본앱 카드 제거 → 키패드 ⋮ 메뉴(기본 앱 상태/설정, 권한, 앱 정보·제한된 설정, 원래 앱으로, 전체 설정). 기본 앱 요청 거부 시 제한된 설정 안내 + ACTION_APPLICATION_DETAILS_SETTINGS 버튼. 통화 기록 권한 없으면 "권한이 필요해요". 검색 탭 → 주소록 탭(가나다순, 초성 인덱스 바, 맨 위 검색칸에 초성 검색·최근 검색 15일 통화 수, 누르면 바로 전화, 길게 누르면 문자/저장).
v3: 아래 탭 바에서 "설정" 탭 제거 → 키패드·최근 통화·주소록 3칸(균등). 설정 화면은 키패드 ⋮ › "전화 설정 전체 보기"로 열고, 왼쪽 위 ← 와 시스템 뒤로 가기로 원래 화면으로 돌아감(설정 화면에서는 탭 바 숨김).
