# 뉴니버스 전화 v1 (시험판) 설치 방법
안내 페이지: https://guy06891577-svg.github.io/newniverse-sand/apk/phone.html
내려받기: https://guy06891577-svg.github.io/newniverse-sand/apk/newniverse-phone-v1-test.apk
패키지 kr.newniverse.phone · 버전 1-test (versionCode 1) · 런처와 같은 뉴니버스 릴리스 서명

1. Play 스토어 › 프로필 › Play 프로텍트 › 톱니바퀴 › "Play 프로텍트로 앱 검사" 잠시 끄기.
2. 폰 크롬에서 내려받기 → 내 파일 › 다운로드 › newniverse-phone-v1-test.apk → (출처 허용) → 설치.
3. 설치 뒤 Play 프로텍트 검사를 다시 켜기.
4. 뉴니버스 전화 열기 → 전화·통화 기록·연락처·알림 권한 허용.
5. 기본 전화 앱 지정: 앱의 "기본 전화 앱으로 설정" → 뉴니버스 전화 → 기본으로 설정.
   (또는 설정 › 애플리케이션 › 기본 앱 선택 › 전화 앱 › 뉴니버스 전화)
되돌리기: 설정 › 애플리케이션 › 기본 앱 선택 › 전화 앱 › 전화. 앱을 지워도 자동으로 원래 앱으로 돌아가요.

권한: CALL_PHONE(바로 걸기), READ_CALL_LOG / WRITE_CALL_LOG(최근 통화 표시·삭제, 부재중 읽음 처리), READ_CONTACTS(이름·초성 검색),
POST_NOTIFICATIONS(수신·통화 중·부재중 알림), USE_FULL_SCREEN_INTENT(잠금 화면 위 수신 화면), VIBRATE, WAKE_LOCK(귀에 대면 화면 끄기).
역할: ROLE_DIALER(기본 전화 앱). 녹음 권한 없음, 인터넷 권한 없음(통화 기록·연락처는 폰 밖으로 나가지 않음).
긴급 전화(112·119 등)는 안드로이드가 항상 폰 기본 전화 앱으로 연결해요.

빌드: ./build.sh (aapt2 · javac 17 · d8 · zipalign · apksigner, android-34, minSdk 26). 서명 키와 비밀번호는 저장소에 없음.
